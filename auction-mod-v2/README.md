# Auction Mod v2 (Fabric, Minecraft 1.21.1)

Press RIGHT SHIFT to open the auction menu (rebind in Controls -> "Auction Mod").
  1 Item  - pick any block (search + scroll)
  2 Price - amount and minimum bid (diamonds)
  3 Time  - duration, then Start Auction

The blocks are taken from your inventory when the auction starts.
Others bid with /auction bid <amount>. Needs to be installed on the server AND on players who want the menu.
Commands still work: /auction start|bid|info|cancel
